# Simple Todo App

- this Project is to sharpen my skills with Validating and Object-Oriented Programming, while helping me understand more complex
  things to work on in JS.

## Functionality

- This simple Todo list project is to help schedule things that need done throughout the day and help ease you with time management.

## Technology

- I used Validations to help refactor the code and simplify it, to make it easier in the future to work on and fix if there are any issues.
  Other tools used were variants of JS under Validatiors and constants with ids.
